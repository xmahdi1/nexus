# Support

Start with the [deployment guide](DEPLOYMENT.md) for installation, migration, and
recovery. For reproducible defects, open a [GitHub issue](https://github.com/xmahdi1/nexus/issues)
and include the relevant version or commit, operating system, installation
method, and expected and observed behavior.

Remove credentials, database contents, private server names, and recovery files
from issue attachments. For a vulnerability, follow the
[private reporting instructions](SECURITY.md).
