# Roadmap

This is the current order of work. Timing depends on verification and review.

1. Finish repository checks, publish installation and recovery guidance, and
   prepare signed container distribution.
2. Extend observed inventory with a topology explorer, scoped search, and
   generated infrastructure documentation.
3. Improve app configuration, networking, and permissions for remote changes.
4. Extend guided CI/CD, Ansible, and alert delivery.
5. Expand application hosting and runtime management after the infrastructure
   work, with optional managed services planned separately.

Check the [README](README.md#what-you-can-do) for features available in the
checkout and [CHANGELOG](CHANGELOG.md) for release status.
