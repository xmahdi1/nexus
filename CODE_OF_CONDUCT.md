# Code of conduct

Treat participants with respect. Discuss decisions and code on their merits.
Harassment, threats, discriminatory behavior, and publishing another person's
private information are unacceptable.

This applies to project issues, pull requests, and other project spaces.
Contact the [maintainer](https://github.com/xmahdi1) privately to report a
concern. The maintainer may remove content, restrict participation, or close a
thread to protect participants.
